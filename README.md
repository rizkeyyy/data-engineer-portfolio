# Indonesia Weather Data ETL Pipeline

## Overview

This project is an end-to-end data engineering pipeline that collects weather data from multiple Indonesian cities, transforms the raw data into a clean format, and loads it into a database for analysis.

## Goals

- Practice Python for data extraction and transformation
- Build a simple ETL pipeline
- Store clean data into a database
- Write SQL queries for analysis
- Add basic geospatial information such as latitude and longitude
- Prepare a portfolio project for a Data Engineer role

## Tech Stack

- Python
- Pandas
- SQL
- SQLite / PostgreSQL
- Apache Airflow
- GitHub
- BigQuery concept

## Pipeline Flow

Raw Data Source
→ Extract with Python
→ Transform and clean data
→ Load into database
→ Analyze with SQL
→ Schedule with Airflow
